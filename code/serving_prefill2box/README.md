# 프리필-2박스 서빙 스택 + ANE 하이브리드

`mlx_lm.server --prefill-2box` 경로에 **길이 분기**를 배선한 온디맨드 스택.
gesicht 가 HTTP 를 받고 층 [32,64) 를 돌리며, epsilon 러너(:39919)가 층 [0,32) 를
돌린다. 양 박스 모두 ANE 하이브리드 프리필을 붙인다.

## 왜 분기가 필요한가

두 스케줄은 **순서가 없다**. 넓은 청크(2048)는 청크당 고정비를 상각하고 ANE 가
발화하는 유일한 폭이지만, 파이프라인 버블을 키운다. 좁은 청크(1024)는 버블이
작지만 ANE 가 비켜선다. 어느 쪽이 이기는지는 **프롬프트가 청크를 몇 개 담느냐**로
갈리므로, 기동 시 하나로 고정할 수 없고 요청마다 골라야 한다. 근거는 원장
`[I168]`·`[RA60]`·`[PA56]`.

ANE 는 정확히 `sequence_length` 토큰 뭉치에서만 발화하므로, seq=2048 로 한 번만
부착해 두면 좁은 스케줄에서는 **자동으로 비켜선다**. 비발화 구간의 부착 비용은
실측으로 −0.5%/−0.3%/+0.6%(8K/10K/32K) — 구분되지 않는다. 두 구간을 한 번의
로드로 서빙하는 근거다.

## 임계값 11264 는 어디서 왔나

2박스 프리필 tok/s, 같은 프로세스 안에서 두 스케줄을 교대로 측정:

| N | ANE@1024 | ANE@2048 | 비 | 대조@1024 | 대조@2048 | 비 |
|---|---:|---:|---:|---:|---:|---:|
| 8192 | 765.0 | 725.8 | 0.949 | 769.0 | 693.4 | 0.902 |
| 9216 | 763.7 | 765.7 | 1.003 | | | |
| 10240 | 776.9 | 777.5 | 1.001 | 779.9 | 721.2 | 0.925 |
| **11264** | 776.8 | **799.2** | **1.029** | | | |
| 12288 | 788.4 | 808.5 | 1.026 | 791.5 | 748.5 | 0.946 |
| 16384 | 791.2 | 850.0 | 1.074 | 802.3 | 764.4 | 0.953 |
| 24576 | 791.3 | 868.6 | 1.098 | | | |
| 32768 | 773.0 | 854.9 | 1.106 | 768.4 | 753.8 | 0.981 |

교차점은 9216 근처지만 9216–10240 은 무승부다. 무승부 구간에서 넓은 청크로
넘어가 봐야 얻는 게 없으므로, **이득이 노이즈를 넘는 첫 길이 11264** 를 임계값으로
잡았다 — 기회비용 0, 잘못 넘어갈 위험 최소.

**대조군(ANE 끔)에서는 넓은 청크가 8K–32K 어디서도 이기지 못한다**(0.902→0.981).
분기는 파이프라인 자체의 성질이 아니라 ANE 가 만든 것이다. 그래서 포크 CLI 에서
`--prefill-2box-chunk-long` 은 옵트인으로 남아 있고, 임계값만 실측 기본값이다.

## 사용

```
~/qwen38/serving_prefill2box/launch_prefill2box.sh     # 기본: :8004, 분기 1024→2048
ANE=0 ~/qwen38/serving_prefill2box/launch_prefill2box.sh   # ANE 없이(대조·격리)
LONG_TOKENS=16384 ~/qwen38/serving_prefill2box/launch_prefill2box.sh
~/qwen38/serving_prefill2box/stop_prefill2box.sh       # TERM 만, KILL 금지
```

런처는 순서대로 강제한다: epsilon 도달 → 양 박스 포크 해시 일치(비트-동일 전제)
→ 러너 기동 후 **ANE 워밍업 로그 확인**(없으면 기동 거부) → 서버 기동 →
`/health` 하드 시한 → 스모크 1요청.

## 서버 플래그

| 플래그 | 뜻 |
|---|---|
| `--prefill-2box HOST:PORT` | 러너 주소 (없으면 단일 박스) |
| `--prefill-2box-split` | 층 분할점 (러너 `--hi` 와 같아야 함) |
| `--prefill-2box-chunk` | 기본(좁은) 청크 |
| `--prefill-2box-chunk-long` | 긴 프롬프트용 청크 — `--prefill-2box-long-tokens` 와 **반드시 함께** |
| `--prefill-2box-long-tokens` | 이 길이 이상이면 넓은 청크 |
| `--prefill-2box-min-tokens` | 이 미만이면 2박스 자체를 쓰지 않음(단일 박스) |

요청마다 어떤 스케줄이 쓰였는지는 서버 로그의 `[prefill_2box] prompt N: ...
at chunk C` 로 확인한다.
